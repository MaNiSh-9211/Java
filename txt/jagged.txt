1. Declaring and Initializing Each Inner Array Individually

int[][] jaggedArray = new int[3][];
jaggedArray[0] = new int[2];
jaggedArray[1] = new int[3];
jaggedArray[2] = new int[1];


2. Declaring and Initializing with Values

int[][] jaggedArray = {
    new int[] {1, 2},
    new int[] {3, 4, 5},
    new int[] {6}
};


3. Using Nested Array Initializers

int[][] jaggedArray = {
    {1, 2},
    {3, 4, 5},
    {6}
};


4. Initializing in a Loop

int[][] jaggedArray = new int[3][];
for (int i = 0; i < jaggedArray.length; i++) {
    jaggedArray[i] = new int[i + 1];
}


5. Using Method to Initialize

public class Main {
    public static void main(String[] args) {
        int rows = 3;
        int[][] jaggedArray = initializeJaggedArray(rows);
        
        // Print the jagged array
        for (int i = 0; i < jaggedArray.length; i++) {
            for (int j = 0; j < jaggedArray[i].length; j++) {
                System.out.print(jaggedArray[i][j] + " ");
            }
            System.out.println();
        }
    }

    public static int[][] initializeJaggedArray(int rows) {
        int[][] jaggedArray = new int[rows][];
        for (int i = 0; i < rows; i++) {
            jaggedArray[i] = new int[i + 1];
        }
        return jaggedArray;
    }
}
Summary
Individual Initialization: Each row is initialized separately.
Array Initializers: Rows can be initialized with predefined values.
Loop Initialization: Rows can be initialized in a loop.
Method Initialization: A method can encapsulate the initialization logic.
These different ways allow you to initialize and work with jagged arrays depending on your specific needs and preferences in your Java program.
