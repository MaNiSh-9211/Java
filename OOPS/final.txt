In Java, the keyword final can be applied to variables, methods, and classes, and it serves different purposes in each context. Here are the differences:

Final Variable
A final variable is a constant. Once it is initialized, it cannot be changed.

Example:


public class Example {
    final int CONSTANT_VALUE = 100;

    public void changeValue() {
        // CONSTANT_VALUE = 200; // This will cause a compilation error
    }
}
Key Points:

A final variable can only be initialized once.
If it is not initialized at the time of declaration, it must be initialized in the constructor.
Useful for defining constants.
Final Method
A final method cannot be overridden by subclasses. This ensures that the implementation of the method remains unchanged in derived classes.

Example:

public class ParentClass {
    public final void display() {
        System.out.println("This is a final method.");
    }
}

public class ChildClass extends ParentClass {
    // The following method will cause a compilation error
    // public void display() {
    //     System.out.println("Attempting to override a final method.");
    // }
}
Key Points:

A final method cannot be overridden by any subclass.
Helps in maintaining the integrity of the method’s behavior.
Often used for methods that are crucial to the correct functioning of the class.
Final Class
A final class cannot be subclassed. No other class can extend a final class.

Example:

public final class FinalClass {
    // Class content
}

// The following class declaration will cause a compilation error
// public class SubClass extends FinalClass {
//     // Cannot subclass a final class
// }
Key Points:

A final class cannot be extended.
Ensures that the class’s design is not altered through inheritance.
Useful for utility or helper classes where inheritance is not necessary.
