It is not compulsory to use static with final in Java. However, using static with final is common in certain contexts because
 it offers specific advantages. Here's a detailed explanation:

When static is Not Required with final A final variable can exist without being static. This is useful when the constant value 
is instance-specific, 
meaning each object of the class might have its own unique constant.

public class Example {
    public final int CONSTANT;

    public Example(int value) {
        this.CONSTANT = value;
    }

    public static void main(String[] args) {
        Example example1 = new Example(10);
        System.out.println("CONSTANT: " + example1.CONSTANT);
        
         Example example2 = new Example(20);
        System.out.println("CONSTANT: " + example2.CONSTANT);
        // Output: CONSTANT: 10
    }
}
