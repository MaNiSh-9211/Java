Explanation
Reference Type:

In your case, var5 is of type Object. The Object class is the root class of all Java classes, and it provides a set of methods that

Any reference of type Object can point to an instance of any class, but you can only call methods defined in the Object class

Given two packages: com.animal and com.main. How can you access the class Dog defined in com.animal from a class in com.main?

You can access Dog without any import statements since both packages are part of the same project.

Import the Dog class using import com.animal.Dog;.
