### Integer to String Conversion Methods

1. **`Integer.toString(int i)`**
   - **Input**: `i = 123`
   - **Function**: Converts an `int` to a `String`.
   - **Output**: `"123"`
   - **Example**:
     ```java
     int num = 123;
     String str = Integer.toString(num); // "123"
     ```

2. **`Integer.toString(int i, int radix)`**
   - **Input**: `i = 255`, `radix = 2`
   - **Function**: Converts an `int` to a `String` using the specified radix (base).
   - **Output**: `"11111111"` (binary representation)
   - **Example**:
     ```java
     int num = 255;
     String strBinary = Integer.toString(num, 2); // "11111111"
     ```

   - **Input**: `i = 255`, `radix = 16`
   - **Function**: Converts an `int` to a `String` using the specified radix (base).
   - **Output**: `"ff"` (hexadecimal representation)
   - **Example**:
     ```java
     int num = 255;
     String strHex = Integer.toString(num, 16); // "ff"
     ```

### Other Data Types to String Conversion Methods
